# `=this.file.name`
`=this.Beschreibung`

Während einer langen Rast kann ein Charakter Wache halten. 
Der Charakter ist in dieser Zeit aufmerksam und kann auf mögliche Gefahren reagieren. 
Der SL kann für heimliches Nähern oder auffällige Bewegungen passende Proben oder Wahrnehmungswürfe verlangen. 
Eine Wache erschwert es Gegnern, das Lager unbemerkt zu erreichen, und kann der Gruppe einen frühen Vorteil verschaffen, wenn ein Angriff droht.
