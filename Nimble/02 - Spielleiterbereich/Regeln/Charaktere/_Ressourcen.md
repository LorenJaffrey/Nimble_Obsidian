## Pool
- fixer Pool
- wird durch Rast wieder aufgefüllt

## Passiv Wachsend
- wird kontinuierlich aufgefüllt

## Aktiv Wachsend
- wird durch Aktionen aufgefüllt


| Art    | begrenzt | Start | Erzeugung | Nutzung    |
| ------ | -------- | ----- | --------- | ---------- |
| Pool   | ja       | voll  | Rast      | subtraktiv |
| Flow   | ja/nein  | leer  | Trigger   | subtraktiv |
| Buffer | ja       | leer  | Trigger   | wenn voll  |
